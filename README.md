# Hi, I'm Jack Wang

Student at Claremont McKenna College. I build quantitative research systems, mostly around markets, and I care about testing ideas honestly before trusting them. Most of my projects end with a written report of what worked, what didn't, and the numbers behind it.

## Featured work

**[kalshi-trading](https://github.com/jack-zhengyangwang/kalshi-trading)** · Python
Autonomous prediction-market research system for soccer markets on Kalshi. Poisson/NegBin pricing models, Kelly sizing with hard caps, a genetic population of strategy agents, and a reproducible paper-trading arena. Two research reports so far, both negative results: Kalshi's prices are well-calibrated probabilities, and public-data models do not beat them. The repo documents every test.

**[soccer-quant](https://github.com/jack-zhengyangwang/soccer-quant)** · Python
Dual-model soccer prediction for the Premier League and Champions League: an ML model on match and xG data combined with LLM analysis of news, injuries, and lineups.

**[CSCI146Project](https://github.com/jack-zhengyangwang/CSCI146Project)** · Python
Data mining final project: machine learning model predicting Valorant round outcomes.
